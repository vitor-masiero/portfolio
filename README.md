# Portfolio

Portfólio pessoal full-stack desenvolvido com React, TypeScript e Vite, com backend em Express/serverless para recursos de contato e integração com APIs.

## Objetivo

Apresentar projetos, habilidades e formas de contato em uma experiência web moderna, responsiva e fácil de manter.

## Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Express
- Serverless HTTP
- Nodemailer
- OpenAI SDK

## Funcionalidades

- Interface responsiva para apresentação profissional
- Componentes reutilizáveis
- API backend para rotas auxiliares
- Endpoint de contato
- Estrutura preparada para deploy em Vercel/Netlify

## Como rodar localmente

```bash
npm install
npm run dev
```

## Scripts úteis

```bash
npm run build      # build client + server
npm run typecheck  # checagem TypeScript
npm run test       # testes com Vitest
```

## Status

Projeto em evolução contínua como vitrine profissional.
